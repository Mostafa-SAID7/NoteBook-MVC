1. HomeController (MVC - Views)
   ├─ Namespace: NoteBook.Web.Controllers
   ├─ Base Class: Controller (MVC)
   ├─ Authentication: None Required
   └─ Actions:
      └─ Index() → Route: "/" (default)
         └─ Returns: View() → Views/Home/Index.cshtml

2. NotesController (REST API)
   ├─ Namespace: NoteBook.Web.Controllers
   ├─ Base Class: ControllerBase (API)
   ├─ Route: /api/notes
   ├─ Authentication: REQUIRED (JWT Bearer Token)
   ├─ Authorization Attribute: [Authorize]
   └─ Actions:
      ├─ GET   GetNotes()        → Returns: IEnumerable<NoteDto> or PaginatedResponse
      ├─ GET   GetNote(id)       → Returns: NoteDto
      ├─ POST  CreateNote()      → Returns: NoteDto (CreatedAtAction 201)
      ├─ PUT   UpdateNote(id)    → Returns: NoteDto
      ├─ DELETE DeleteNote(id)   → Returns: NoContent 204
      └─ GET   SearchNotes()     → Returns: IEnumerable<NoteDto>

3. AuthController (REST API)
   ├─ Namespace: NoteBook.Web.Controllers
   ├─ Base Class: ControllerBase (API)
   ├─ Route: /api/auth
   ├─ Authentication: NONE REQUIRED
   ├─ Authorization Attribute: None ([AllowAnonymous] implicit)
   └─ Actions:
      └─ POST Login(request) → Returns: { token, userId, username }
         └─ Generates JWT Token with Claims:
            ├─ NameIdentifier (UserId)
            └─ Name (Username)

4. HealthController (REST API)
   ├─ Namespace: NoteBook.Web.Controllers
   ├─ Base Class: ControllerBase (API)
   ├─ Route: /api/health
   ├─ Authentication: NOT REQUIRED ([AllowAnonymous])
   └─ Actions:
      ├─ GET Get()   → Health Status JSON with DB check
      ├─ GET Live()  → Liveness Probe (always 200)
      └─ GET Ready() → Readiness Probe (500 if DB down)

Authentication:
POST   /api/auth/login                         ← Get JWT Token

Notes Management (Requires JWT):

POST   /api/notes                              ← Create new note
PUT    /api/notes/{id}                         ← Update note
DELETE /api/notes/{id}                         ← Delete note
GET    /api/notes/search?term=query            ← Search notes

Health Monitoring (No JWT required):
GET    /api/health                             ← Full health check
GET    /api/health/live                        ← Liveness probe
GET    /api/health/ready                       ← Readiness probe

Views (MVC):
GET    /                                       ← Homepage (Index.cshtml)
